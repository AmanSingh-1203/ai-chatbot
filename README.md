# ai-chatbot

This repository started as a small chatbot experiment. I added a simple visual game using Pygame.

Visual game: visual_game.py

How to run the visual game

1. Install dependencies (preferably inside a virtualenv):

   pip install -r requirements.txt

2. Run the game:

   python visual_game.py

Controls
- Left / A  : Move left
- Right / D : Move right
- Space     : Shoot
- P         : Pause
- R         : Restart (after game over)
- Esc       : Quit

Notes
- The game is a small "Space Defender" style shooter with simple shapes (no external assets).
- If you want a different game (Tic-Tac-Toe with GUI, Snake with graphics, platformer), tell me which one and I can add it next.
