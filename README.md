# ai-chatbot

This repository started as a small chatbot experiment. I added a simple visual game using Pygame.

Visual game: visual_game.py

How to run the visual game

Double-click the platform-appropriate launcher file so the game opens automatically:

- Windows: double-click run_game.bat
- macOS / Linux: double-click run_game.sh (you may need to mark it executable: chmod +x run_game.sh)
- Or run the Python launcher directly: python start_game.py

Notes
- The launcher will try to install dependencies from requirements.txt using pip if they are not already installed. It uses the same Python interpreter that runs the launcher.
- Controls
  - Left / A  : Move left
  - Right / D : Move right
  - Space     : Shoot
  - P         : Pause
  - R         : Restart (after game over)
  - Esc       : Quit
